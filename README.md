# 📚 Library Management System

A command-line Library Management System built with Node.js and JavaScript.

This project is part of my **Backend Development Phase 1** and focuses on JavaScript fundamentals, CRUD operations, business logic, validation, modules, and asynchronous user input.

---

## 🚀 Features

- Add books
- List all books
- Search books by title or author
- Borrow books
- Return books
- Delete books
- Book availability tracking
- Input validation
- Error handling
- Interactive CLI menu
- Modular project structure

---

## 🛠️ Technologies

- JavaScript
- Node.js
- Node.js `readline`
- CommonJS Modules
- npm
